# Reaction Network Configuration

ELM-Wet-Redox uses PFLOTRAN input decks to define the reactions evaluated
through Alquimia. The decks are generated by `REDOX-PFLOTRAN/network_for_ELM.py`
from a versioned YAML configuration.

## Configuration Files

The canonical configuration is:

```text
REDOX-PFLOTRAN/configs/elm_reaction_network_parameters.yaml
```

It contains the shared defaults, the complete reaction table, and the standard
deck variants. Site or experiment profiles can inherit those defaults and
record only their differences. For example:

```text
REDOX-PFLOTRAN/configs/la2_h2meth_noh2.yaml
```

This profile enables sulfate cycling and the methylated-carbon reactions,
selects no-H2 MeC fermentation, and selects H2-consuming methylotrophic
methanogenesis.

## Reaction Table

Each key under `chemistry.reactions` is a stable reaction identifier:

```yaml
version: 2

chemistry:
  reactions:
    acetoclastic_methanogenesis:
      name: Acetaclastic methanogenesis
      enabled: true
      rate_constant: 2.5e-9
      activation_energy: 8.0e4
      monod_half_saturations:
        "Acetate-": 4.0e-3
        "H+": 2.884031503126606e-6
      inhibition_half_saturations:
        "O2(aq)": 2.0e-5
```

The fields have these roles:

| Field | Meaning |
| --- | --- |
| `name` | Model-facing display name written into the PFLOTRAN deck |
| `enabled` | Whether the reaction is included |
| `formulation` | Optional structural choice for reactions with supported alternatives |
| `rate_constant` | Maximum microbial reaction rate |
| `activation_energy` | Arrhenius temperature-response parameter |
| `monod_half_saturations` | Species and constants for increasing, saturating responses |
| `inhibition_half_saturations` | Species and constants for decreasing inhibition responses |

Quote chemical species names in YAML. Characters such as `+`, `-`, and
parentheses are valid in quoted keys.

Most Monod entries are single numbers. A reaction can use a mapping when it
also needs a threshold or pool-normalized response:

```yaml
monod_half_saturations:
  "Acetate-":
    value: 1.0e-3
    threshold: 1.1e-15
```

Most inhibition entries are also single numbers and generate PFLOTRAN
`TYPE MONOD`. The rare inverse response is marked explicitly while remaining
in the inhibition column:

```yaml
inhibition_half_saturations:
  "H+":
    value: 2.884031503126606e-6
    type: inverse_monod
```

## Formulations

Only reactions with implemented structural alternatives accept a
`formulation` field. The current choices are:

| Reaction | Formulations |
| --- | --- |
| `mec_fermentation` | `h2_producing`, `no_h2` |
| `methylotrophic_methanogenesis` | `h2_independent`, `h2_consuming` |

The formulation controls stoichiometry in the generator. Scalar kinetics
remain in the same reaction row.

## Profiles And Inheritance

A short profile inherits another YAML file with top-level `extends`:

```yaml
version: 2
extends: elm_reaction_network_parameters.yaml

chemistry:
  reactions:
    mec_fermentation:
      enabled: true
      formulation: no_h2
      rate_constant: 1.66666667e-7
```

The inherited file is resolved relative to the profile file. Nested mappings
are merged recursively, so omitted settings retain their parent values.
Inheritance cycles and unknown reaction fields are rejected.

Use profiles for a named, scientifically meaningful network configuration.
Avoid duplicating the full canonical table for every site.

## Deck Variants

`chemistry.deck_variants` defines the standard generated decks. A variant
selects either the `simple` or `aqueous` builder and may override settings or
reaction rows:

```yaml
deck_variants:
  o2_notad:
    builder: aqueous
    overrides:
      reactions:
        acetoclastic_methanogenesis:
          monod_half_saturations:
            "Acetate-": 1.0e-3

  o2_lowFe_notad:
    extends: o2_notad
    overrides:
      settings:
        organic_matter:
          DOM_Fe_content: 1.0e-5
```

Variant inheritance is explicit. The effective order is:

1. canonical configuration;
2. inherited profile overrides;
3. parent deck variant;
4. child deck variant.

## Generate Decks

Generate the canonical deck collection:

```bash
cd REDOX-PFLOTRAN
python network_for_ELM.py
```

Generate the LA2 configuration in a separate directory:

```bash
python network_for_ELM.py \
  --config configs/la2_h2meth_noh2.yaml \
  --output-dir /path/to/la2-decks
```

List configured deck variants:

```bash
python network_for_ELM.py \
  --config configs/la2_h2meth_noh2.yaml \
  --list-decks
```

The generator writes the usual eight PFLOTRAN decks plus:

```text
resolved_reaction_network.yaml
```

The resolved file records the fully inherited configuration used for every
deck variant. Keep it with generated decks and simulation provenance.

The topology is selected in YAML through `enabled` and `formulation`. There is
no separate topology command-line option.

## BOA Parameter Targets

The workbench can create a trial-specific deck by overriding one or more
reaction-table scalars. Each BOA target identifies the deck, reaction, and
path within the row:

```yaml
log10_acetaclastic_rate:
  backend: alquimia
  source_config_path: /path/to/configs/la2_h2meth_noh2.yaml
  generator_script: /path/to/REDOX-PFLOTRAN/network_for_ELM.py
  deck_name: o2_notad
  reaction_id: acetoclastic_methanogenesis
  parameter_path: [rate_constant]
  expected_source_value: 2.5e-9
  transform: log10_to_linear
```

A half-saturation target uses a longer path:

```yaml
parameter_path: [monod_half_saturations, "Acetate-"]
```

Compatible Alquimia targets are applied to one self-contained trial YAML, then
the generator runs once. Each trial stores that YAML, the generated deck,
resolved configuration, checksums, one shared generation record, and
per-parameter audit data.

## Compatibility

Changing a scalar parameter while preserving species, reaction names, and
stoichiometry is usually a deck-only experiment. Structural changes can alter
the Alquimia state expected by ELM.

Treat these as compatibility-sensitive changes:

- enabling or disabling reactions that introduce species;
- changing a reaction formulation;
- adding, removing, renaming, or reordering primary species;
- changing the mineral or gas basis;
- changing model-facing reaction names.

Restart files are tied to the chemistry state that created them. Use a new
spinup for a structurally different network unless a restart-remapping workflow
has been explicitly validated. Do not overwrite an archived deck set that was
used for a scientific run.
