## Workshop Goals

Participants should leave able to:

- Explain what ELM-Wet-Redox simulates and how ELM, Alquimia, and PFLOTRAN
  interact.
- Log in to OSC/Cardinal and work in the project environment.
- Understand where code, input data, case directories, run directories, and
  output files live.
- Create and inspect an LA2 ELM-Wet-Redox case.
- Create draft point-site domain, surface, and wetland-forcing files.
- Submit and monitor jobs on Slurm.
- Analyze model output with Python.
- Compare model results with observations and launch a small BOA experiment.
- Understand how to adapt the LA2 workflow to a new site.
